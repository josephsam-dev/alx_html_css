# Headphones Landing Page 🎧

This project is part of the **ALX Front-End program**.  
It demonstrates how to transform a Figma design into a responsive web page using **HTML** and **CSS**.

---

## 🧠 Project Overview

The **Headphones Landing Page** was built following a Figma design, ensuring accurate layout, typography, and responsiveness.  
The page adapts automatically to different screen sizes — including a dedicated **mobile layout** at 480px width or less.

---

## 🧩 Features

- ✅ Responsive design (mobile view under 480px)
- 🎨 Custom fonts (`Source Sans Pro` and `Spin Cycle OT`)
- 🖱️ Hover & Active states:
  - Links: `#FF6565`
  - Buttons: `opacity: 0.9`
- 📏 Max width of content: **1000px** (centered)
- 💻 Clean, semantic HTML structure
